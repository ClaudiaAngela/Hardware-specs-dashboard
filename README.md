## Overview
A static web page presenting local network (LAN) specifications, connected hardware devices, and system performance monitoring.

## Key Sections
* **Profile:** Author contact and identification.
* **Hardware & Specs:** Overview table of connected devices (Router, Laptop, Printer, Smartphone).
* **Network Topology:** Local network diagram image.
* **Connection Data:** MAC address, local IP, and upload/download bandwidth.
* **Resource Monitoring:** Performance metrics showing CPU, memory, and process usage.

## Interactive Features
* **Dual View (Gallery / Slideshow):**  
  * By default, screenshots are displayed in a compact static gallery.  
  * Double-clicking the *"Monitorizare resurse"* section header switches the page into **Slideshow (Carousel)** mode.
* **Automatic & Manual Carousel:**  
  * Automatic transition between screenshots every 3 seconds (fade effect).  
  * Manual navigation via previous/next buttons (`❮` / `❯`) and indicator dots (*dots*).

## Tech Stack
* HTML5
* CSS3 (Flexbox, Neon Shadow Effects, Animations)
* JavaScript (DOM Manipulation, Timers, Event Listeners)

## How to Run

### Option 1: Run Locally from Source
1. **Download the Project:**
   * Click the green **Code** button at the top of the repository and select **Download ZIP**, then extract the contents on your computer.
   * *Alternatively*, clone the repository using Git:
     ```bash
     git clone <REPOSITORY_URL>
     ```
2. **Verify File Structure:** Ensure that all asset files (`Diagrama.png`, `slide1.png`, `slide2.png`, `slide3.png`) and code files (`index.html`, `ClaudiaJ_style.css`, `ClaudiaJ_script.js`) remain in the same root folder.
3. **Launch the Page:** Double-click `index.html` or open it with any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge).
